# kaggle_finetune/kernel_source — AGENTS.md
Purpose: the code that runs inside the PRIVATE Kaggle notebook `karamabumokh/got-gpt2-continue-finetune`. Kaggle runs one file, so `../build_kernel_bundle.py` packs these modules into `../kernel_push/`. Edit here, then rebuild; never edit the bundle. Run modes: `smoke` (Karam's five-step sanity ladder), `full` (the real continued training), `dry` and `dry_full` (local CPU crash tests of the ladder and of the full-run path with a tiny random model).

## Files
- `run_settings.py` — every switch: learning rate 3e-5, 5% warmup then cosine to 10%, clipping 1.0, fp16, gradient checkpointing (fits a T4), batch sizes, half the book windows per epoch, evaluation interval, early-stopping patience, time limit, the data-review switches, the sanity-ladder thresholds, the 10 fixed questions and the sampling settings.
- `gpt_network.py` — GPT-2 medium with the same parameter names as the saved weights (so `model.pth` drops into the Space unchanged; scores match the Space's network to 2e-4), with fused layer norm, PyTorch's memory-saving attention and optional per-block gradient checkpointing.
- `pair_filters.py` — the free data-review fixes on TRAINING pairs only: unnamed subject, questions citing "the passage", no named person or place, near-duplicates, repeated questions, answers under 8 words, and cutting ", indicating ..." tails. Keeps about 34,000 of 60,062.
- `training_examples.py` — exact training prompt + answer + one end token, answer-only labels, 1024-token book windows, length-grouped batch plans that mix pair and book batches, padding.
- `model_evaluation.py` — validation losses (answer-only, Karam's all-token number, held-out book text) with perplexities, and sampled answers to the fixed questions with the reason each answer stopped.
- `training_loop.py` — AdamW (no decay on biases and norms), warmup + cosine schedule, fp16 loss scaling (records the steps it skips), gradient clipping, a chunked loss that never holds all word scores at once, evaluations, early stopping against the current model's score, best-checkpoint saving, curve pictures and the full-run time estimate.
- `sanity_ladder.py` — the five checks: decoded examples, step-0 loss of the current checkpoint (answer-only about 3.0 and all-token about 1.8 expected), over-fitting one tiny batch, a small slice (losses, NaN, gradient norms, schedule shape), answers stopping at the end token; plus a save-and-strict-reload test.
- `run_entry.py` — finds the two private datasets under `/kaggle/input`, prepares the data, then runs the smoke ladder (report rewritten after every check, errors included) or the full run (guards, training, `model.pth`, `before_after.json`) in `/kaggle/working`.
