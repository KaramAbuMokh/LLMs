# kaggle_finetune/mixed_run/mixed_kernel_source — AGENTS.md
Purpose: the code of the mixed books + question-answer run that runs inside the PRIVATE Kaggle notebook `karamabumokh/got-gpt2-mixed-books-qa-finetune`. Kaggle runs one file, so `../build_mixed_bundle.py` packs these modules together with the morning run's shared modules from `../../kernel_source/` (network, prompt and padding, scoring and sampling, training session, two sanity checks). Edit here, then rebuild; never edit the bundle. Modes: `mixed_smoke` (the ladder), `mixed_full` (the real run), `dry_smoke` and `dry_full` (local CPU crash tests with a tiny random model).

## Files
- `mixed_settings.py` — the mixing switches on top of the morning settings: the start weights (Karam's original, because smoke v1 showed this morning's model is already at its best on these pairs), 512-token book blocks with a 64-token unscored overlap, book blocks per step (worked out so every pair and every block is used once per epoch), the pair share of each step's loss (picked on the smoke sweep), the sweep and over-fit sizes, 3 epochs at most, a check every 250 steps, patience 4, the fingerprints of the two weight files, and the morning model's expected start numbers.
- `mixed_examples.py` — cuts each book part into blocks (the overlap is context only, so each token is scored once per epoch), counts each book's share, and makes the one shuffled stream where every step holds 32 pairs AND about 5 book blocks.
- `mixed_training.py` — one optimizer step on both batches: pair share x answer-only pair loss + the rest x book loss; everything else is the morning run's training session.
- `fact_questions.py` — the 30 fact questions (the 10 fixed ones first, then 20 with short known answers such as Needle or Winterfell) and the word rules that mark an answer right; 2 right of 3 samples = right.
- `mixed_evaluation.py` — scores a model the same way for all three: all 1,233 held-out pairs, the 816 answerable ones, Karam's all-token loss, the held-out book passage, the stop rate on the 10 fixed questions and the facts score, sampled with the Space's settings.
- `mixed_ladder.py` — the four smoke checks: data and weight fingerprints, the morning model's start numbers, a tiny mixed batch memorised, and a 200-step run of each tried mix from the start weights (no NaN, sane gradients, warmup then cosine, answers still stop, held-out losses not hurt), which also picks the mix (lowest held-out answer + book loss, near-ties to more books) and tests saving.
- `mixed_entry.py` — finds the attached data and weights under `/kaggle/input`, tokenises everything, then runs the ladder (report `mixed_ladder_report.json`) or the full run (scores this morning's model and the original, trains from the start weights, scores the result: `model.pth`, `comparison.json`, history, curves, guards) in `/kaggle/working`.
